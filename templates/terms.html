利用規約

最終更新日：年

本規約は、動画ツールキット（以下「本サービス」）の利用条件を定めるものです。ユーザーは本サービスを利用することで本規約に同意したものとみなします。

第1条（サービスの内容）

本サービスは、ブラウザ上で動画の圧縮・音声抽出・GIF変換・無音化を行う無料のオンラインツールです。

第2条（禁止事項）

以下の行為を禁止します。

  • 著作権・肖像権等の第三者の権利を侵害するコンテンツの処理
  • 違法なコンテンツの処理・配布を目的とした利用
  • 本サービスのサーバーに過大な負荷をかける行為
  • 本サービスを通じた不正アクセスやシステムへの攻撃
  • その他、公序良俗に反する利用

第3条（免責事項）

  • 本サービスは「現状のまま」提供されます。処理結果の品質・正確性について保証しません。
  • サービスの停止・中断・データの損失等について、運営者は一切の責任を負いません。
  • ユーザーが本サービスを利用したことにより生じた損害について、運営者は責任を負いません。

第4条（アップロードファイルの取り扱い）

動画圧縮処理はユーザーの端末（ブラウザ）上で完結します。音声抽出・GIF変換・無音化処理においては、ファイルが一時的にサーバーへ送信されますが、処理完了後10分以内に自動削除されます。当サービスはアップロードされたファイルを第三者へ共有・販売・解析等に使用しません。

第5条（知的財産権）

本サービスを使用して作成・変換されたファイルの権利は、元のファイルの権利者に帰属します。運営者は変換後のファイルに対して何らの権利も主張しません。

第6条（規約の変更）

運営者は予告なく本規約を変更できます。変更後も本サービスを利用し続けた場合、変更後の規約に同意したものとみなします。

よくある質問（FAQ）

ツールの安全性・使い方についてよくある質問をまとめました。

動画圧縮はサーバーを経由しません。圧縮処理はすべてユーザーのブラウザ上（FFmpeg.wasm）で実行されるため、動画ファイルがインターネット上に送信されることは一切ありません。

音声抽出・GIF変換・無音化はサーバー側で処理を行いますが、アップロードされたファイルは処理完了後最大10分以内に自動削除されます。第三者がファイルにアクセスすることはできません。
すべての機能を完全無料でご利用いただけます。アカウント登録・メールアドレスの入力・クレジットカードの登録は不要です。
入力形式として MP4 / MOV / AVI / MKV / WebM / WMV / FLV / M4V / TS / MTS / M2TS / 3GP / OGV に対応しています。出力は動画圧縮・無音化が MP4、音声抽出が MP3、GIF変換が GIF 形式です。
「画質モード」から「⚖️ バランス」または「🎬 画質優先」を選択してください。また、目標サイズを大きくすることでビットレートが上がり画質が向上します。目標サイズが極端に小さい場合（5MB以下など）、「画質優先」モードでは解像度を自動的に下げてピクセルあたりのビットレートを確保します。
UIはスマートフォン対応のレスポンシブデザインです。ただし、FFmpeg.wasmを使う動画圧縮処理はブラウザのメモリを使用するため、大きなファイルの処理では端末スペックに応じて時間がかかる場合があります。
自分が権利を持つ動画、または著作権者から許諾を得た動画のみをご利用ください。著作権法に違反するコンテンツの処理・配布は本サービスの利用規約で禁止しており、法律により処罰される場合があります。
